# XBox Friend
## Use this method if you are on console

Unfortunately the console version of Minecraft doesn't allow you to add a server to your game directly, but don't fear: I made this strange work around!

## Step 1: Open Minecraft
This *should* be linked with your XBox/Microsoft account already, but be sure to login to it if you aren't.

## Step 2: Open the Social tab
Click play, then in the top right a button title "Social" should appear

## Step 3: Add Friend
Select search for players and type:

```
SebMCServer
```

A user should pop up, click the add button.

## Step 4: Wait a bit
The XBox user will automatically accept your friend request after a minute or so.

## Step 5: Join SebMCServer's World
Depending on what platform you are playing on the world may appear on the social tab or the worlds tab, either works!

:::tip[Tip]

Once you do this once the server should pop up in the same place every time you open the game!

:::
