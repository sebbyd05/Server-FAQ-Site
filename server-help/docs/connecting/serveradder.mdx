# Server tab
## This method does not work on console

## Step 1: Open Minecraft

## Step 2: Open the Servers tab

## Step 3: Add the Server
Press the button labeled "Add Server". Set the name to whatever you want, and under server address enter:
```
bedrock.bleemfleem.com
```
Leave the port section the same, or if it is empty enter:
```
19132
```

## Step 4: Press add and play

:::warning[Scroll down]

Once the server is added it appears in the very bottom of the server list!

:::
