# Cross-Platform Invintory
*This is completely optional*

Do you play on both Bedrock and Java? If so you can link your accounts. This will allow you to have one invintory and set of statistics shared between your Bedrock and Java accounts!


:::danger[Save Your Stuff!]

Put all your stuff in chests **before** doing this proscess to avoid loosing things forever!

:::

## What is account linking?
This server uses a piece of software to trick a Bedrock client into thinking it's a Bedrock server. Sense Bedrock and Java use a different username systems there could be two seprate accounts with the same username. To fix this the server puts a . before bedrock usernames.
If you have both Bedrock and Java accounts you can tell the server to use your Bedrock account to login to your Java account. This makes it so no matter what platform you join the server from your Java data will be used.

## Okay, so how do it?
Go to https://link.geysermc.org, there you will be walked through the proscess!
